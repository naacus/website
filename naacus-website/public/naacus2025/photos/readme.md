# NAACUS 2025 Photos

This folder contains photos from the NAACUS gathering in July 2025.

## Guidelines for Adding Photos

### File Naming Convention
- Use descriptive names: `keynote-speaker-1.jpg`, `workshop-leadership.jpg`, `cultural-celebration.jpg`
- Include date if relevant: `2025-07-15-opening-ceremony.jpg`
- Use lowercase with hyphens instead of spaces

### File Format
- Preferred format: JPEG (.jpg)
- Alternative: PNG (.png) for graphics with transparency
- Optimize images before uploading (recommended max 2MB per photo)

### Recommended Dimensions
- Hero/banner images: 1920x1080px or similar 16:9 ratio
- Gallery thumbnails: 800x600px or similar 4:3 ratio
- Portrait photos: 600x800px

### Content Suggestions
1. **Opening Ceremony**: Procession, liturgical celebrations
2. **Keynote Speakers**: Featured speakers at the podium
3. **Workshops**: Participants in various sessions
4. **Cultural Events**: Dance, music, traditional dress
5. **Mass & Liturgy**: Eucharistic celebrations, choir performances
6. **Networking**: People connecting and fellowship
7. **Youth Activities**: Young members participating
8. **Group Photos**: Regional delegations, ministry groups
9. **Venue**: Conference facilities, dining areas
10. **Behind the Scenes**: Setup, volunteers, planning

### Permissions & Copyright
- Ensure you have permission to use all photos
- Obtain consent from identifiable individuals
- Credit photographers when applicable
- Include photo credits in file metadata or separate credits.txt file

### Organization
Consider creating subfolders:
- `opening-ceremony/`
- `keynote-speakers/`
- `workshops/`
- `cultural-celebrations/`
- `mass-liturgy/`
- `networking/`
- `youth/`
- `group-photos/`

### Accessibility
- Provide descriptive alt text for each photo
- Consider creating a `photo-descriptions.json` file with alt text for each image
