# Security Policy

## Supported Versions

Security updates are applied to the active `develop` branch.

| Branch   | Supported |
|----------|-----------|
| develop  | :white_check_mark: |
| others   | :x: |

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue.

1. Email: info@naacus.org
2. Subject: `Security Vulnerability Report`
3. Include:
   - Affected component/file
   - Reproduction steps
   - Potential impact
   - Suggested remediation (if available)

You should receive an initial response within 3 business days.

## Disclosure Process

- We validate and triage reports privately.
- We work on a fix and deployment timeline based on severity.
- We coordinate responsible disclosure once remediation is available.
